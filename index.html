GitHub 文件加速

GitHub 文件链接带不带协议头都可以，支持 release、archive 以及文件，右键复制出来的链接都是符合标准的。

更多用法、clone 加速请参考 这篇文章。

注意：不支持项目文件夹。

合法输入示例：

分支源码：https://github.com/SECTL/project/archive/master.zip

release 源码：https://github.com/SECTL/project/archive/v0.1.0.tar.gz

release 文件：https://github.com/SECTL/project/releases/download/v0.1.0/example.zip

分支文件：https://github.com/SECTL/project/blob/master/filename

基于 hunshcn/gh-proxy，使用 Cloudflare Workers，开源于 GitHub sectl/gh-proxy
